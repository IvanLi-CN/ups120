# UPS 主控风扇调速需求与任务规划

> 版本：2025-10-19  
> 适用分支：`feature/fan-control`  
> 目标硬件：ESP32‑S3 主控 + 两线直流风扇（`FAN_EN`=GPIO39，`FAN_PWM`=GPIO40，经 RC 滤波调制 LDO）

## 1. 背景与现状

- 硬件链路采用两线风扇，无转速反馈，PWM→电压通过 LDO 反馈网络实现。
- 现有固件仅提供 GPIO/LEDC 初始化与占空比示例，不含温度闭环或安全保护。
- TSENS 读取存在显著偏差：在环境约 32 °C 情况下测得 ≈7 °C（`raw≈35`），说明当前采样/换算流程未正确应用 eFuse 校准或量程配置。

## 2. 功能需求

| 编号 | 类型 | 描述 |
| --- | --- | --- |
| FR-1 | 功能 | 解析 ESP32‑S3 TSENS 传感器，按官方 HAL/IDF 流程完成初始化、量程选择、eFuse 校准补偿，获得合理芯温。 |
| FR-2 | 功能 | 构建温度→占空比（GPIO40 实际 PWM%）的控制策略，按 VIN 状态分支：<br>• VIN 存在（当前默认）：`<35 °C` 关风扇；`35–45 °C` 固定 96%；`>45 °C` 时以 45 °C 为目标在 96%~0% 范围内压制温度；温度降回 `<35 °C` 再次停转。<br>• VIN 缺失：`<40 °C` 关风扇；`≥40 °C` 全部以 45 °C 为目标调节，占空比限定在 96%~0%。|
| FR-3 | 功能 | 支持占空比限斜率（默认 ±5%/500 ms）与温度滞回（默认 3 °C）。 |
| FR-4 | 功能 | 温度 ≥ 80 °C 时强制 `FAN_EN=High`、占空比 100%；温度异常（读数无效或校准缺失）时进入安全占空比（默认 50%）。 |
| FR-5 | 功能 | 定期日志输出（建议每 2 s）包含温度、原始 ADC、当前量程、校准参数、目标/实际占空比、故障标志。 |
| FR-6 | 功能 | 提供启动蜂鸣提示或诊断输出，帮助定位 TSENS 初始化失败、校准缺失等问题。 |
| FR-7 | 非功能 | 所有硬件操作遵循 60 s 内完成的运行约束；日志需友好可读，便于远程调试。 |

## 3. 技术约束

- **HAL 选型**：使用 `esp-hal`（当前版本 1.0.0-rc.1），需参考其 `tsens`、`ledc` API，必要时补齐底层寄存器操作。
- **TSENS 校准**：按照 IDF `temperature_sensor_hal.c`、`sar_periph_ctrl_common.c`、`esp_efuse_rtc_calib.c` 的顺序初始化：启用 APB_SARADC 时钟、REGI2C、电源、量程；利用 eFuse `TEMP_CALIB`（BLOCK2 bit132..140）读取 `delta_T`，按 0.1°C 缩放补偿。
- **硬件限制**：两线风扇无转速反馈，仅能开环；若未来加入 PCNT，应保持模块化封装。
- **最低占空比**：实测风扇在实际 PWM 输出低于 ≈97% 时无法启动，固件需将“最低转速”钳制在 `96%`。
- **运行约束**：`make ups-run` 监控受限（espflash monitor 可能退出），需提供备用串口读取脚本或说明。

## 4. 任务拆解

1. **TSENS 驱动修复**
   - 复刻 IDF 的 `temperature_sensor_power_acquire()/temp_sensor_get_raw_value()` 流程，采用 `esp_hal::peripherals::SYSTEM/RTC_CNTL/SENS` 寄存器直接配置；
   - 实现量程表（`offset/reg_val`）与自动切换策略；确保默认量程 `-10~80 °C`；
   - 读取 eFuse `TEMP_CALIB`，处理版本判断（`rtc_calib_version()==1`）及无校准 fallback；
   - 输出诊断信息：raw、base（未补偿）温度、delta_T、量程索引。

2. **风扇控制逻辑**
   - 建立温度采样调度（建议 500 ms 周期）；实现开环曲线、滞回、限斜率；
   - 集成 EN 控制：0% → 关闭 GPIO39，高占空比 → 先拉高 EN 再设置 duty；
   - 异常保护：传感器失效或温度越界时进入安全模式并记录日志。

3. **配置与可调参数**
   - 提供常量或结构体集中定义温度节点、占空比、滞回、限斜率、安全占空比；
   - 若可能，读取 `cfg` 或 `const` 以便未来迁移到外部配置。

4. **日志与测试工具**
   - 统一日志格式：`TEMP=xxx°C RAW=yy ATTR=z DELTA=... DUTY=... MODE=...`；
   - 提供 README/文档更新，说明如何使用 `cat /dev/cu.usbmodem*` 或 Python 脚本读取日志；
   - 记录测试步骤与结果（真实硬件验证、环境温度与芯温差、稳定性）。

## 5. 验收标准

- 正常室温（25–32 °C）下，温度日志应落在合理区间（允许芯温高于环境 5–10 °C），不再出现固定 ≈7 °C 的异常。
- 通过加热或风扇阻挡实验，温度升高时占空比正确提升，≥80 °C 时进入强制全速。
- 断开或故意破坏 TSENS 流程（例如禁用校准）时，系统进入安全占空比并打印错误。
- `make ups-run` 60 s 内可获取至少一次完整日志；辅助脚本说明可在 README 内找到。
